# Barnen

Övningsspel för Olver, publicerade med GitHub Pages.

- `s-galaxy/` – S Galaxy: rymdspel för att öva ljudet s (läxa från logopeden). Allt i en fil, inget bygge behövs.

Spelen använder mikrofonen i webbläsaren. Inget spelas in eller skickas någonstans; framsteg sparas bara i webbläsaren på enheten.

Adress: https://emelielofdahl.github.io/Barnen/ (spelet: https://emelielofdahl.github.io/Barnen/s-galaxy/)
